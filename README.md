# Session 2 — JavaScript Homework

Practice for variables, conditions, loops, arrays and objects.
Every file is **one task**. Read the comments at the top, write your code under `// your code here`,
and compare your console output with the `Expected output` block.

## Tasks

| Folder | Tasks |
|---|---|
| `01-variables` | trip cost, cafe receipt |
| `02-conditions` | weather advice, museum ticket, login check, *stretch:* triangle type |
| `03-loops` | even numbers, savings goal, star triangle, *stretch:* digit sum |
| `04-arrays` | Omani cities, exam results, reverse an array, *stretch:* find the index |
| `05-objects` | car, cafe menu, order total, *stretch:* count by category |
| `06-final` | library (uses everything) |

Files marked **stretch** are optional, but try them.

## How to start

1. Click **Use this template → Create a new repository** on GitHub. Name it `session-02-homework`.
2. Clone **your** new repository:
   ```bash
   git clone <your-repo-url>
   ```
3. Open the folder in VS Code.

## How to run a task

1. Open `index.html` in the browser (double-click it, or right-click → Open with → Chrome).
2. Open DevTools Console: `Cmd + Option + J` (Mac) or `Ctrl + Shift + J` (Windows).
3. In `index.html`, change the `src` of the `<script>` tag to the task you are working on, save, and refresh the page.

If you have Node.js installed, you can also run a file in the VS Code terminal:

```bash
node 01-variables/01-trip-cost.js
```

## Rules

- Do not use things we have not learned yet (`.reverse()`, `.indexOf()`, `Math.max`, `Math.min`, functions). Loops and `if` are enough.
- Your output does not have to match the expected text letter by letter, but the **numbers and results must be the same**.
- **Commit after every task**, for example:
  ```bash
  git add .
  git commit -m "Complete 01-variables/01-trip-cost"
  ```
- Push when you are done:
  ```bash
  git push
  ```

## How to submit

Paste the link to **your** GitHub repository into the assignment in Moodle before the deadline.
